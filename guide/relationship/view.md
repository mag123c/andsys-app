# 관계도 보기

> 복잡한 인물 관계를 한눈에!

**인터랙티브 그래프**로 캐릭터 간의 관계를 시각화합니다.

![관계도 화면](/screenshots/relationships.png)

## 관계도 접근

1. 소설 상세 페이지에서 **관계도** 탭 클릭
2. 또는 에디터 우측 패널의 **관계도** 버튼 클릭

## 그래프 구성

- **노드(원)**: 캐릭터
- **엣지(선)**: 관계

### 노드

- 캐릭터 이름이 표시됩니다
- 프로필 이미지가 있으면 함께 표시
- **클릭**하면 캐릭터 정보 패널이 열립니다

### 엣지

- 두 캐릭터를 연결하는 선
- **관계 유형별로 색상**이 다릅니다
- **화살표**로 관계 방향 표시

## 그래프 조작

### 확대/축소
- **마우스 휠**로 확대/축소
- 또는 우측 하단 **+/-** 버튼

### 이동
- 빈 공간을 **드래그**하여 화면 이동

### 노드 이동
- 노드를 **드래그**하여 원하는 위치로 이동
- 놓으면 위치가 저장됩니다

## 미니맵

그래프가 커지면 우측 하단에 **미니맵**이 표시됩니다.

- 전체 그래프 구조를 한눈에 확인
- 미니맵 클릭으로 해당 위치로 이동
- 3초간 조작이 없으면 자동으로 숨김

## 자동 레이아웃

캐릭터와 관계가 많아지면 자동으로 **최적의 배치**를 계산합니다.

Dagre 알고리즘을 사용하여 겹침을 최소화하고 가독성을 높여요.
