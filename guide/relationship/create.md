# 관계 만들기

> 두 캐릭터 사이의 관계를 설정하고 싶어요!

그래프에서 직접 관계를 연결하거나, 다이얼로그로 추가할 수 있습니다.

## 관계 추가 방법

### 방법 1: 그래프에서 연결

1. 시작 캐릭터 노드에서 **엣지 핸들**(작은 점) 드래그
2. 끝 캐릭터 노드에 **드롭**
3. 관계 설정 다이얼로그가 열림
4. 관계 유형과 설명 입력

### 방법 2: 버튼으로 추가

1. **관계 추가** 버튼 클릭
2. 시작 캐릭터, 끝 캐릭터 선택
3. 관계 유형과 설명 입력
4. 저장

## 관계 유형

| 유형 | 색상 | 예시 |
|------|------|------|
| 가족 | 보라 | 부모, 형제, 사촌 |
| 친구 | 파랑 | 소꿉친구, 동기 |
| 연인 | 분홍 | 연인, 약혼자 |
| 라이벌 | 주황 | 경쟁자, 숙적 |
| 적 | 빨강 | 원수, 악당 |
| 동료 | 초록 | 동료, 파트너 |
| 스승/제자 | 노랑 | 사제, 멘토 |
| 기타 | 회색 | 직접 정의 |

## 관계 설명

관계 유형만으로 부족하다면 **설명**을 추가하세요.

예:
- 유형: 가족
- 설명: "쌍둥이 형제, 서로를 질투함"

## 양방향 관계

기본적으로 관계는 **단방향**입니다.

예: "A → B: 짝사랑"

**양방향**으로 설정하면 반대 방향도 표시됩니다.

예: "A ↔ B: 연인"

::: tip
"A가 B를 좋아하지만 B는 A를 싫어한다"처럼 비대칭 관계는 **두 개의 단방향 관계**로 표현하세요.
:::

## 관계 수정

엣지(선)를 **클릭**하면 수정 다이얼로그가 열립니다.

## 관계 삭제

수정 다이얼로그에서 **삭제** 버튼으로 삭제합니다.
