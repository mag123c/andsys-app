# 플롯 메모

> 회차별 줄거리나 메모를 기록하세요.

## 플롯 메모란?

각 회차에 간단한 메모를 작성할 수 있는 기능입니다.

- 이번 화의 줄거리
- 복선, 중요 사건 기록
- TODO 메모
- 다음 화 연결 포인트

## 사용 방법

1. 에디터 화면에서 **플롯 메모** 버튼 클릭
2. 텍스트 영역이 펼쳐집니다
3. 내용 입력 → **0.5초 후 자동 저장**

## 위치

에디터 상단, 툴바 위에 있습니다.

```
┌─────────────────────────────────┐
│ ← 목록   1화 - 시작             │
├─────────────────────────────────┤
│ 📄 플롯 메모                  ∨ │  ← 여기를 클릭
├─────────────────────────────────┤
│ 리디바탕 ∨ │ 12 ∨ │ B I U │... │
└─────────────────────────────────┘
```

## 활용 예시

```
- 이번 화: A 캐릭터와 B 캐릭터 첫 만남
- 복선: C의 정체에 대한 힌트 심기
- 다음 화 연결: 갈등 고조, 결별 장면으로 이어짐
- TODO: 대화 어색한 부분 다듬기
```

::: tip 집필 팁
플롯 메모를 활용하면 회차 간 흐름을 놓치지 않고 연재할 수 있어요.
:::

## 자동 저장

플롯 메모도 본문과 마찬가지로 **자동 저장**됩니다.

- 0.5초 대기 후 저장
- "자동 저장됨" 표시 확인
