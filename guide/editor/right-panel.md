# 우측 패널 활용

> 시놉시스를 보면서 글을 쓰고 싶어요!

우측 패널에서 시놉시스, 캐릭터, 회차 목록을 **참조하며 집필**할 수 있습니다.

## 패널 구성

우측 패널은 **탭**으로 구성되어 있어요:

| 탭 | 내용 |
|----|------|
| 시놉시스 | 프로젝트 시놉시스 (읽기 전용) |
| 캐릭터 | 등장인물 목록 |
| 회차 | 전체 회차 목록 |

## 패널 접기/펼치기

- 우측 패널 하단의 **◀** 버튼으로 접기
- 접힌 상태에서 **▶** 버튼으로 펼치기

::: tip
패널 상태는 **저장**되어, 다음에 에디터를 열어도 유지됩니다.
:::

## 시놉시스 탭

시놉시스 페이지에서 작성한 내용이 **읽기 전용**으로 표시됩니다.

글을 쓰다가 전체 흐름을 확인하고 싶을 때 유용해요.

## 캐릭터 탭

등록된 캐릭터들이 **미니 카드**로 표시됩니다.

- 캐릭터 카드를 **클릭**하면 상세 정보 모달이 열립니다
- 캐릭터 정보를 확인하며 대사나 행동을 일관성 있게 작성하세요

## 회차 탭

모든 회차 목록이 표시됩니다.

- **현재 회차**는 하이라이트 표시
- 다른 회차 클릭으로 이동

## 관계도 버튼

패널 상단의 **관계도** 버튼을 클릭하면 관계도가 **모달**로 열립니다.

복잡한 인물 관계를 확인하며 글을 쓸 수 있어요.
