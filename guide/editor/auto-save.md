# 자동 저장

> 저장 버튼을 안 눌렀는데 괜찮을까요?

걱정 마세요! 4ndSYS는 **자동 저장** 시스템을 사용합니다.

## 작동 방식

```
글 작성 → 2초 대기 → 자동 저장 → "저장됨" 표시
```

1. 글을 작성하면 **2초 후** 자동으로 저장됩니다
2. 계속 타이핑하면 타이머가 리셋됩니다
3. 타이핑을 멈추고 2초가 지나면 저장!

## 저장 상태

하단 상태바 중앙에서 현재 저장 상태를 확인할 수 있어요:

| 상태 | 색상 | 의미 |
|------|------|------|
| 저장됨 | 회색 | 모든 내용이 안전하게 저장됨 |
| 저장 중... | 회색 | 저장 진행 중 |
| 저장 안 됨 | 노란색 | 저장되지 않은 변경사항 있음 |
| 저장 실패 | 빨간색 | 저장 중 오류 발생 |

## 즉시 저장

급하게 저장하고 싶다면:

- **`Ctrl+S`** (Mac: `Cmd+S`)

자동 저장을 기다리지 않고 바로 저장됩니다.

## 페이지 이탈 시

저장되지 않은 내용이 있는 상태에서 페이지를 떠나려고 하면:

1. **경고 메시지**가 표시됩니다
2. 탭이 **백그라운드로 가면 자동 저장**됩니다
3. 브라우저를 **닫기 전에 저장**을 시도합니다

::: tip 안심하세요
4ndSYS는 여러 겹의 안전장치로 데이터 손실을 방지합니다.
:::

## 저장은 어디에 되나요?

모든 저장은 먼저 **로컬(IndexedDB)**에 저장됩니다.

회원이라면 이후 자동으로 클라우드와 동기화됩니다.
