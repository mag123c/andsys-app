# 에디터 기본 사용법

> 드디어 글을 쓸 시간이에요!

4ndSYS 에디터는 **집필에 집중**할 수 있도록 심플하게 설계되었습니다.

## 에디터 구성

에디터는 세 영역으로 나뉩니다:

![에디터 화면](/screenshots/editor.png)

### 상단 헤더
- **왼쪽**: 회차 목록으로 돌아가기 버튼
- **중앙**: 회차 제목 (클릭하여 수정)

### 본문 영역
- **왼쪽 사이드바**: 회차 목록 (빠른 이동)
- **중앙**: 에디터 본문 + 상단 툴바 (폰트, 폰트 크기, 서식, 정렬)
- **오른쪽 패널**: 시놉시스, 캐릭터, 현재 회차 정보 참조

### 하단 상태바
- **좌측**: 글자수 (공백 포함/제외 토글)
- **중앙**: 저장 상태
- **우측**: 클립보드 복사, TXT 내보내기 버튼

## 제목 수정

상단의 제목을 **클릭**하면 수정할 수 있어요.

- 클릭 → 입력 → **Enter** 또는 바깥 클릭으로 저장
- **Esc**로 취소

## 본문 작성

에디터 본문 영역에서 자유롭게 글을 작성하세요.

- 일반적인 텍스트 에디터처럼 작동합니다
- **Enter**로 문단 구분
- **Shift+Enter**로 같은 문단 내 줄바꿈

## 저장 상태 확인

하단 상태바 중앙에서 저장 상태를 확인할 수 있어요:

| 상태 | 의미 |
|------|------|
| 저장됨 | 모든 내용이 저장됨 |
| 저장 중... | 저장 진행 중 |
| 저장 안 됨 | 저장되지 않은 변경사항 있음 |

## 글자수 확인

하단 상태바 좌측에서 현재 글자수를 실시간으로 확인할 수 있습니다.

- 클릭하면 **공백 포함/제외** 모드가 전환됩니다

## 왼쪽 사이드바

다른 회차로 빠르게 이동할 수 있는 회차 목록입니다.

- 현재 회차는 **하이라이트** 표시
- 회차 클릭으로 이동 (저장되지 않은 내용은 자동 저장)
