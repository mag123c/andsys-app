# 서식 적용하기

> 대사를 강조하고 싶어요!

툴바에서 다양한 서식을 적용할 수 있습니다.

## 지원하는 서식

| 서식 | 단축키 | 설명 |
|------|--------|------|
| **굵게** | `Ctrl+B` | 강조하고 싶은 텍스트 |
| *기울임* | `Ctrl+I` | 생각, 독백, 외래어 등 |
| <u>밑줄</u> | `Ctrl+U` | 추가 강조 |

## 서식 적용 방법

### 방법 1: 텍스트 선택 후 적용

1. 서식을 적용할 텍스트를 **드래그하여 선택**
2. 툴바에서 원하는 서식 버튼 클릭
3. 또는 **단축키** 사용

### 방법 2: 먼저 서식 활성화

1. 툴바에서 서식 버튼 클릭 (활성화)
2. 텍스트 입력
3. 다시 버튼 클릭하여 해제

## 서식 해제

이미 적용된 서식을 해제하려면:

1. 해당 텍스트 **선택**
2. 같은 서식 버튼을 **다시 클릭**

## 텍스트 정렬

| 정렬 | 설명 |
|------|------|
| 왼쪽 정렬 | 기본값 |
| 가운데 정렬 | 제목, 구분선 등 |

::: tip 웹소설 팁
웹소설에서는 보통 **왼쪽 정렬**을 유지하고, 장 구분이나 시간 경과 표현에만 가운데 정렬을 사용해요.
:::
