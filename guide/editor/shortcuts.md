# 키보드 단축키

> 마우스 없이도 빠르게!

자주 쓰는 단축키를 익혀두면 글쓰기 속도가 훨씬 빨라져요.

## 서식 단축키

| 단축키 | Mac | 기능 |
|--------|-----|------|
| `Ctrl+B` | `Cmd+B` | **굵게** |
| `Ctrl+I` | `Cmd+I` | *기울임* |
| `Ctrl+U` | `Cmd+U` | <u>밑줄</u> |

## 편집 단축키

| 단축키 | Mac | 기능 |
|--------|-----|------|
| `Ctrl+Z` | `Cmd+Z` | 실행 취소 |
| `Ctrl+Shift+Z` | `Cmd+Shift+Z` | 다시 실행 |
| `Ctrl+Y` | `Cmd+Y` | 다시 실행 (대체) |

## 저장 단축키

| 단축키 | Mac | 기능 |
|--------|-----|------|
| `Ctrl+S` | `Cmd+S` | 즉시 저장 |

::: tip
자동 저장이 있지만, 중요한 내용을 작성한 후에는 `Ctrl+S`로 확실하게 저장하세요!
:::

## 텍스트 선택

| 단축키 | 기능 |
|--------|------|
| `Ctrl+A` | 전체 선택 |
| `Shift+방향키` | 텍스트 선택 |
| `Ctrl+Shift+방향키` | 단어 단위 선택 |
| `더블클릭` | 단어 선택 |
| `트리플클릭` | 문단 선택 |

## 커서 이동

| 단축키 | 기능 |
|--------|------|
| `Home` | 줄 맨 앞으로 |
| `End` | 줄 맨 뒤로 |
| `Ctrl+Home` | 문서 맨 앞으로 |
| `Ctrl+End` | 문서 맨 뒤로 |
| `Ctrl+방향키` | 단어 단위 이동 |
