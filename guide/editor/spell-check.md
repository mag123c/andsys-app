# 맞춤법 검사

> 작성한 글의 맞춤법을 검사합니다.

::: warning 현재 점검 중
맞춤법 검사 서비스가 현재 점검 중입니다.
빠른 시일 내에 복구될 예정입니다.
:::

## 기능 소개

맞춤법 검사 기능을 통해 글의 완성도를 높일 수 있습니다.

- 맞춤법/띄어쓰기 오류 검출
- 수정 제안 확인
- 원클릭 교정

## 사용 방법 (복구 후)

1. 에디터 하단 상태바에서 **맞춤법 검사** 버튼 클릭
2. 오류 목록이 시트로 표시됩니다
3. 각 오류를 클릭하면 자동 교정
4. **"모두 적용"** 버튼으로 일괄 교정

## 위치

에디터 하단 상태바 우측에 있습니다.

```
┌─────────────────────────────────────────┐
│ 1,234자 (공백 제외)  ✓ 저장됨   🔍 📋 ⬇ │
│                                    ↑    │
│                              맞춤법 검사 │
└─────────────────────────────────────────┘
```

## 검사 결과

| 항목 | 설명 |
|------|------|
| 오류 단어 | 맞춤법이 틀린 단어 |
| 수정 제안 | 올바른 표기 제안 |
| 오류 유형 | 맞춤법, 띄어쓰기 등 |

::: tip 팁
글자수가 많으면 검사 시간이 오래 걸릴 수 있어요.
완성된 회차 단위로 검사하는 것을 권장합니다.
:::

## 지원 검사 항목

- 한글 맞춤법
- 띄어쓰기
- 표준어 사용

::: info 서비스 복구 안내
맞춤법 검사 서비스 복구 시 공지사항으로 안내드릴 예정입니다.
:::
