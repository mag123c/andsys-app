# 폰트 변경

> 명조체로 글을 쓰고 싶어요!

취향에 맞는 폰트와 크기로 더 편하게 글을 쓰세요.

## 폰트 변경 방법

### 방법 1: 에디터 툴바에서 변경

현재 문서의 폰트를 변경합니다:

1. 에디터 상단 **툴바**에서 폰트 선택 드롭다운 클릭
2. 원하는 폰트 선택
3. 즉시 적용!

### 폰트 크기 변경

툴바의 폰트 크기 드롭다운에서 원하는 크기를 선택하세요:

| 크기 | 용도 |
|------|------|
| 10pt | 작은 글씨 |
| 11pt | 약간 작게 |
| **12pt** | 기본값 |
| 14pt | 약간 크게 |
| 16pt | 큰 글씨 |

### 방법 2: 기본 폰트 설정

모든 에디터에 적용될 기본 폰트를 설정합니다:

1. **설정** 페이지 이동
2. **기본 글꼴** 섹션에서 폰트 선택
3. 이후 열리는 모든 에디터에 적용

## 지원 폰트

### 고딕 계열
- **Pretendard**: 현대적인 고딕체
- **본고딕 (Noto Sans KR)**: Google 폰트
- **나눔스퀘어 네오**: 깔끔한 고딕
- **Gmarket Sans**: 귀여운 느낌

### 명조 계열
- **리디바탕**: 리디북스 명조
- **본명조 (Noto Serif KR)**: Google 폰트
- **마루 부리**: 우아한 명조

::: tip 웹소설 추천
많은 웹소설 작가들이 **명조체**를 선호해요. 읽는 사람도 편하고, 소설 분위기가 살아나거든요.
:::

## 폰트 미리보기

설정 페이지에서 각 폰트 버튼이 **해당 폰트로 표시**되므로, 클릭하기 전에 미리보기를 할 수 있어요.
