# 맞춤법 검사

> 글 쓰다가 맞춤법이 걱정되시나요?

4ndSYS는 **맞춤법 검사** 기능을 제공합니다. 띄어쓰기, 맞춤법 오류를 찾아 수정 제안을 받을 수 있어요.

## 사용 방법

1. 회차 편집 화면에서 하단 상태바의 **맞춤법 검사** 버튼 클릭
2. 오류 목록에서 **적용** 버튼 클릭

## 검사 결과 화면

검사가 완료되면 발견된 오류 목록이 표시됩니다:

| 항목 | 설명 |
|------|------|
| 원문 | 오류가 있는 단어 (취소선) |
| 수정 제안 | 권장 수정 단어 |
| 설명 | 띄어쓰기 오류, 맞춤법 오류 등 |
| 다른 제안 | 대체 가능한 다른 단어들 |

## 오류 수정하기

### 개별 적용

각 오류 옆의 **적용** 버튼을 클릭하면 해당 오류만 수정됩니다.

### 모두 적용

하단의 **모두 적용** 버튼을 클릭하면 모든 오류가 한 번에 수정됩니다.

::: tip 적용 후에도 수정 가능
오류를 적용한 후에도 에디터에서 직접 수정할 수 있어요. 자동 수정이 마음에 들지 않으면 `Ctrl+Z`로 되돌릴 수 있습니다.
:::

## 제한 사항

### 최대 2,000자

맞춤법 검사는 **앞 2,000자**만 검사됩니다. 2,000자를 초과하는 글은 일부만 검사되며, 이 경우 경고 메시지가 표시됩니다.

::: warning 긴 글은 나눠서 검사하세요
2,000자를 초과하는 회차는 앞부분만 검사됩니다. 전체 검사를 원하시면 회차를 나눠서 작성하거나, 외부 맞춤법 검사기를 병행해 주세요.
:::

### 동일 단어 전체 교체

같은 오류 단어가 여러 번 등장하면 **모두 한꺼번에 수정**됩니다. 특정 위치만 수정하고 싶다면 적용 후 `Ctrl+Z`로 되돌리고 직접 수정하세요.

## 오류 유형

| 유형 | 예시 |
|------|------|
| 띄어쓰기 | "모래속에" → "모래 속에" |
| 맞춤법 | "반갑읍니다" → "반갑습니다" |
| 어미 | "굵은게" → "굵은 게" |

## FAQ

### 검사가 안 되거나 오래 걸려요

맞춤법 검사는 외부 서비스를 이용합니다. 네트워크 상태에 따라 느려질 수 있어요. 잠시 후 다시 시도해 주세요.

### 검사 결과가 이상해요

맞춤법 검사기가 모든 경우를 완벽하게 처리하지는 못합니다. 제안이 이상하다면 무시하고 직접 수정하세요.

### 오프라인에서도 검사할 수 있나요?

아니요, 맞춤법 검사는 **온라인 상태**에서만 사용할 수 있습니다.
