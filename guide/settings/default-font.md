# 기본 폰트 설정

> 매번 폰트를 바꾸기 귀찮아요!

기본 폰트를 설정하면 **모든 에디터**에 자동 적용됩니다.

## 기본 폰트 설정 방법

1. **설정** 페이지 이동
2. **기본 글꼴** 섹션 확인
3. 원하는 폰트 버튼 클릭
4. 완료!

## 에디터와의 관계

- **기본 폰트**: 에디터를 열 때 적용되는 폰트
- **에디터 폰트**: 현재 문서에만 적용

에디터에서 폰트를 변경하면 **해당 문서**에만 적용되고, 다른 문서는 기본 폰트가 적용됩니다.

## 지원 폰트

### 고딕 계열
- Pretendard
- 본고딕 (Noto Sans KR)
- 나눔스퀘어 네오
- Gmarket Sans

### 명조 계열
- 리디바탕
- 본명조 (Noto Serif KR)
- 마루 부리

## 폰트 미리보기

각 폰트 버튼이 **해당 폰트로 표시**되므로, 클릭 전에 미리 확인할 수 있어요.
