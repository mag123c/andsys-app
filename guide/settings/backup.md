# 데이터 백업

> 혹시 모를 상황에 대비하고 싶어요!

모든 소설과 회차를 **JSON 파일**로 내보낼 수 있습니다.

## 백업 방법

1. **설정** 페이지 이동
2. **데이터 백업** 섹션 확인
3. **전체 백업 다운로드** 버튼 클릭
4. `4ndsys-backup-날짜.json` 파일 다운로드

## 백업 파일 내용

백업 파일에는 다음이 포함됩니다:

- 모든 소설 정보 (제목, 설명, 장르)
- 모든 회차 내용 (Tiptap JSON 형식)
- 글자수, 생성/수정 시간

::: warning 포함되지 않는 항목
- 표지 이미지 (별도 저장 권장)
- 시놉시스
- 캐릭터 정보
- 관계도

추후 업데이트에서 추가될 예정입니다.
:::

## 백업 파일 구조

```json
{
  "version": "1.0",
  "exportedAt": "2025-01-15T10:30:00Z",
  "projects": [
    {
      "id": "...",
      "title": "나의 첫 번째 소설",
      "chapters": [
        {
          "title": "1화",
          "content": { /* Tiptap JSON */ },
          "wordCount": 3245
        }
      ]
    }
  ]
}
```

## 백업 주기 권장

| 작업량 | 권장 주기 |
|--------|----------|
| 매일 연재 | 주 1회 |
| 주 1-2회 | 월 1회 |
| 가끔 | 중요 진행 후 |

::: tip
회원 가입하면 **자동 클라우드 백업**이 되어 수동 백업이 덜 중요해져요!
:::

## 복원

현재 백업 파일을 직접 복원하는 기능은 제공하지 않습니다.

백업 파일은 **만약의 상황**을 대비한 것으로, JSON 형식이라 필요시 다른 도구로 읽을 수 있어요.
