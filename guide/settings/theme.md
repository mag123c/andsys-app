# 테마 변경

> 다크모드로 바꾸고 싶어요!

눈이 편한 테마를 선택하세요.

## 테마 옵션

| 테마 | 설명 |
|------|------|
| 라이트 | 밝은 배경, 어두운 글씨 |
| 다크 | 어두운 배경, 밝은 글씨 |
| 시스템 | OS 설정에 따라 자동 전환 |

## 테마 변경 방법

1. **설정** 페이지 이동
2. **테마** 섹션에서 원하는 옵션 클릭
3. 즉시 적용!

## 시스템 테마

**시스템**을 선택하면 운영체제 설정에 따라 자동으로 전환됩니다.

- macOS/iOS: 시스템 환경설정 > 디스플레이 > 라이트/다크
- Windows: 설정 > 개인 설정 > 색 > 모드 선택

::: tip
밤에는 다크모드가 눈의 피로를 줄여줘요.
:::
