# 커스텀 필드

> 기본 필드로는 부족해요!

원하는 정보 필드를 **직접 추가**할 수 있습니다.

![커스텀 필드 설정 화면](/screenshots/custom-fields.png)

## 커스텀 필드란?

기본 제공되는 필드(이름, 나이, 성별 등) 외에 **사용자가 정의하는 추가 필드**입니다.

예를 들어:
- **마법 속성**: 불, 물, 바람
- **무공 수위**: 절정, 화경, 현경
- **각성 능력**: 염동력
- **혈액형**: AB형
- **좋아하는 음식**: 파스타

## 커스텀 필드 추가

1. 캐릭터 수정 다이얼로그 열기
2. 하단의 **+ 필드 추가** 버튼 클릭
3. **필드 이름**과 **값** 입력
4. 저장

## 커스텀 필드 삭제

각 커스텀 필드 옆의 **X** 버튼으로 삭제할 수 있습니다.

## 활용 예시

### 판타지 소설
```
마나량: 3,500
속성: 화염
등급: S급
길드: 빛의 기사단
```

### 무협 소설
```
내공: 갑자 60년
무공: 독고구검
문파: 화산파
무림 별호: 매화검선
```

### 현대물
```
직장: 한강그룹 비서실
연봉: 1억
취미: 독서, 요리
반려동물: 고양이 (이름: 치즈)
```

::: tip
커스텀 필드는 **무제한**으로 추가할 수 있어요. 필요한 만큼 마음껏 추가하세요!
:::
