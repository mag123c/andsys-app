# 히스토리 복원

> 실수로 캐릭터 정보를 지웠어요!

캐릭터 수정 내역이 **자동으로 저장**되어, 이전 버전으로 복원할 수 있습니다.

## 히스토리 확인

1. 캐릭터 수정 다이얼로그 열기
2. 상단의 **히스토리** 버튼 클릭
3. 버전 목록 확인

## 버전 목록

각 버전에는 다음 정보가 표시됩니다:

- **수정 시간**: 언제 저장되었는지
- **변경 내용**: 어떤 필드가 변경되었는지

## 복원하기

1. 복원하려는 버전 선택
2. **복원** 버튼 클릭
3. 확인 후 적용

::: warning 주의
복원하면 현재 정보가 선택한 버전으로 **덮어씌워집니다**.
:::

## 히스토리가 저장되는 시점

캐릭터 정보를 **저장할 때마다** 자동으로 스냅샷이 생성됩니다.

별도로 "버전 저장" 버튼을 누를 필요 없어요!

::: tip
시놉시스도 동일한 방식으로 히스토리를 지원합니다.
:::
