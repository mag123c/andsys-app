# 캐릭터 추가

> 등장인물을 정리하고 싶어요!

캐릭터 페이지에서 등장인물 정보를 체계적으로 관리하세요.

![등장인물 페이지](/screenshots/characters.png)

## 캐릭터 추가하기

1. 소설 상세 페이지에서 **캐릭터** 탭 클릭
2. **+ 추가** 버튼 클릭
3. 캐릭터 정보 입력
4. **저장** 버튼 클릭

## 캐릭터 정보 필드

### 기본 정보
| 필드 | 필수 | 설명 |
|------|:----:|------|
| 이름 | ✅ | 캐릭터 이름 |
| 별명 | - | 닉네임, 호칭 등 |
| 나이 | - | 숫자 |
| 성별 | - | 자유 입력 |
| 종족 | - | 인간, 엘프, 뱀파이어 등 |

### 신체 정보
- **키**: cm 단위
- **몸무게**: kg 단위
- **외형**: 외모 설명

### 성격 & 배경
- **MBTI**: INFP, ENTJ 등
- **성격**: 성격 특징
- **교육**: 학력, 수련 이력 등
- **직업**: 현재 직업
- **소속**: 소속 단체, 가문 등
- **배경**: 개인사, 과거 이야기

### 프로필 이미지

캐릭터를 대표하는 이미지를 설정할 수 있어요.

- 지원 형식: JPG, PNG, WebP
- 카드와 관계도 노드에 표시됩니다

## 캐릭터 수정

캐릭터 카드를 **클릭**하면 수정 다이얼로그가 열립니다.

## 캐릭터 삭제

수정 다이얼로그 하단의 **삭제** 버튼으로 삭제할 수 있습니다.

::: warning 주의
캐릭터를 삭제하면 해당 캐릭터와 연결된 **관계도 데이터도 함께 삭제**됩니다.
:::
