# 시놉시스 버전 히스토리

> 어제 쓴 시놉시스가 더 좋았는데...

시놉시스 수정 내역이 **자동으로 저장**됩니다.

## 히스토리 확인

1. 시놉시스 페이지 이동
2. 상단의 **히스토리** 버튼 클릭
3. 버전 목록 확인

## 버전 복원

1. 복원하려는 버전 선택
2. 내용 미리보기 확인
3. **복원** 버튼 클릭

::: warning
복원하면 현재 시놉시스가 선택한 버전으로 덮어씌워집니다.
:::

## 저장 시점

시놉시스를 **저장할 때마다** 자동으로 스냅샷이 생성됩니다.

- 자동 저장 (2초 debounce)
- 수동 저장 (Ctrl+S)

별도로 "버전 저장" 버튼을 누를 필요 없어요!
