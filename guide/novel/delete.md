# 소설 삭제

> 더 이상 필요 없는 소설을 정리하고 싶어요.

소설을 삭제하면 관련된 모든 데이터가 함께 삭제됩니다.

## 삭제 방법

### 방법 1: 소설 목록에서

1. 삭제할 소설 카드의 **메뉴(⋮)** 버튼 클릭
2. **삭제** 선택
3. 확인 다이얼로그에서 **삭제** 클릭

### 방법 2: 소설 상세에서

1. 소설 상세 페이지 이동
2. 제목 옆 **설정(⚙️)** 아이콘 클릭
3. 하단 **삭제** 버튼 클릭
4. 확인 후 삭제

## 함께 삭제되는 데이터

소설을 삭제하면 다음 데이터가 **모두 삭제**됩니다:

- ✅ 모든 회차 내용
- ✅ 시놉시스
- ✅ 모든 캐릭터
- ✅ 모든 관계도
- ✅ 버전 히스토리

::: danger 주의
삭제된 소설은 **복구할 수 없습니다**!

삭제 전에 꼭 백업하세요.
:::
