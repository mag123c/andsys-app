# 회차 순서 변경

> 1화랑 2화 순서를 바꾸고 싶어요!

드래그 앤 드롭으로 간단하게 순서를 변경할 수 있습니다.

## 순서 변경 방법

1. 이동하려는 회차 카드의 **왼쪽 핸들(⋮⋮)** 을 클릭
2. 원하는 위치로 **드래그**
3. 놓으면 자동 저장!

## 드래그 앤 드롭 팁

- 핸들을 클릭한 채로 **위아래로** 이동
- 이동 중에는 파란색 가이드라인이 표시됩니다
- 놓는 순간 순서가 저장되므로 별도 저장 버튼 없음

## 키보드로 순서 변경

마우스가 불편하다면 키보드로도 가능해요:

1. 회차 카드에 **포커스** (Tab 키)
2. **Space** 키로 선택
3. **방향키**로 이동
4. **Space** 키로 확정

::: tip
모바일에서도 터치로 드래그 앤 드롭이 가능합니다.
:::
