# 새 소설 만들기

> 새 아이디어가 떠올랐나요?

소설 목록에서 **새 소설** 버튼을 눌러 새로운 프로젝트를 시작하세요.

## 소설 생성하기

1. 소설 목록 페이지(`/novels`)에서 **새 소설** 버튼 클릭
2. 소설 정보 입력:
   - **제목** (필수): 소설 제목
   - **설명**: 간단한 소개
   - **장르**: 로맨스, 판타지, 현대 등
   - **표지 이미지**: 소설을 대표하는 이미지
3. **만들기** 버튼 클릭

## 입력 항목 설명

### 제목

소설의 제목입니다. 나중에 언제든 수정할 수 있어요.

### 설명

소설에 대한 간단한 소개입니다. 시놉시스와는 별개로, 목록에서 소설을 구분하기 위한 용도예요.

### 장르

장르 태그를 설정하면 소설 카드에 표시됩니다. 원하는 텍스트를 자유롭게 입력하세요.

예: `로맨스`, `판타지`, `무협`, `현대물`, `BL` 등

### 표지 이미지

소설 카드에 표시될 이미지입니다. 설정하지 않으면 제목 첫 글자가 표시돼요.

- 지원 형식: JPG, PNG, WebP
- 권장 비율: 2:3 (세로)

::: tip
표지 이미지는 브라우저에 Base64로 저장되므로, 너무 큰 이미지는 피하는 게 좋아요.
:::

## 생성 후

소설이 생성되면 **소설 상세 페이지**로 이동합니다. 여기서:

- 회차 추가
- 시놉시스 작성
- 캐릭터 등록
- 관계도 설정

을 할 수 있어요.
