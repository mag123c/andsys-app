# 표지 이미지 설정

> 멋진 표지를 달고 싶어요!

소설 카드에 표시될 표지 이미지를 설정하세요.

![표지 이미지 설정 화면](/screenshots/cover-upload.png)

## 이미지 설정 방법

1. 소설 생성 또는 수정 다이얼로그 열기
2. **표지 이미지** 영역 클릭
3. 이미지 파일 선택
4. 저장

## 지원 형식

- **JPG/JPEG**
- **PNG**
- **WebP**

## 권장 사양

| 항목 | 권장 |
|------|------|
| 비율 | 2:3 (세로) |
| 해상도 | 400x600px 이상 |
| 용량 | 1MB 이하 |

::: warning 주의
이미지는 **Base64로 브라우저에 저장**됩니다. 너무 큰 이미지는 성능에 영향을 줄 수 있어요.
:::

## 기본 표지

표지 이미지를 설정하지 않으면 **제목 첫 글자**가 표시됩니다.

예: "마법사의 여정" → **마**

## 이미지 삭제

수정 다이얼로그에서 이미지 영역의 **X** 버튼으로 삭제할 수 있습니다.
