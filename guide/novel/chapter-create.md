# 회차 추가하기

> 이제 본격적으로 글을 써볼까요?

소설 상세 페이지에서 **새 회차** 버튼을 눌러 회차를 추가하세요.

## 회차 생성하기

1. 소설 상세 페이지에서 **새 회차** 버튼 클릭
2. 회차 제목 입력
3. **추가** 버튼 클릭
4. 생성된 회차 카드를 클릭하여 에디터로 이동

## 회차 카드 정보

각 회차 카드에는 다음 정보가 표시됩니다:

- **제목**: 회차 제목
- **글자수**: 현재까지 작성된 글자 수
- **수정일**: 마지막으로 수정한 날짜

## 회차 정렬

회차는 기본적으로 **생성 순서**대로 정렬됩니다.

순서를 바꾸고 싶다면? [회차 순서 변경 →](./chapter-reorder)

## 회차 삭제

회차 카드 우측 상단의 **메뉴(⋮)** 버튼을 클릭하면 삭제할 수 있습니다.

::: warning 주의
삭제된 회차는 복구할 수 없습니다. 신중하게 결정하세요!
:::
