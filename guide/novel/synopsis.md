# 시놉시스 작성

> 전체 줄거리를 정리하고 싶어요!

시놉시스 페이지에서 소설의 전체 흐름을 관리하세요.

## 시놉시스 페이지 접근

1. 소설 상세 페이지 이동
2. **시놉시스** 탭 클릭

## 시놉시스 작성

에디터와 동일한 인터페이스로 시놉시스를 작성할 수 있습니다.

- **서식** 적용 가능 (굵게, 기울임, 밑줄)
- **폰트** 변경 가능
- **자동 저장** 지원

## 시놉시스 활용법

### 전체 줄거리
처음부터 끝까지의 큰 흐름을 정리하세요.

```
도입: 주인공이 이세계에 떨어진다
전개: 마법을 익히고 동료를 만난다
위기: 마왕군의 습격
절정: 마왕과의 대결
결말: 세계를 구하고 귀환
```

### 회차별 요약
각 회차의 핵심 내용을 미리 적어두면 연재에 도움이 돼요.

### 복선 정리
나중에 회수할 복선들을 메모해두세요.

## 에디터에서 참조

집필 중에 **우측 패널 > 시놉시스 탭**에서 시놉시스를 바로 확인할 수 있어요.
