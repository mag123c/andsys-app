# 게스트 vs 회원

> 회원가입 없이도 쓸 수 있다고요?

네! 4ndSYS는 **게스트 모드**를 지원합니다. 하지만 두 모드에는 중요한 차이가 있어요.

## 비교표

| 기능 | 게스트 | 회원 |
|------|:------:|:----:|
| 소설 작성 | O | O |
| 회차 관리 | O | O |
| 캐릭터 관리 | O | O |
| 관계도 | O | O |
| 자동 저장 | O | O |
| **서버 백업** | X | O |
| **다른 기기에서 접속** | X | O |
| **브라우저 데이터 삭제 후 복구** | X | O |
| **공유 링크 생성** | X | O |

::: warning 핵심 차이
**회원가입 = 서버 백업 = 데이터 안전**

게스트는 브라우저에만 저장되어, 데이터 삭제 시 복구가 불가능합니다.
:::

## 게스트 모드 (로컬)

게스트로 사용하면 모든 데이터가 **현재 브라우저 내부**에만 저장됩니다.

사이드바에 **"로컬"** 뱃지가 표시됩니다.

### 이런 경우 데이터가 사라져요

- 브라우저 "사이트 데이터" 삭제 (쿠키, 캐시 전체 삭제 시 포함)
- 시크릿/프라이빗 모드 종료
- 브라우저 재설치
- 다른 브라우저에서 접속

::: danger 주의
브라우저 설정에서 "인터넷 사용 기록 삭제" 시 "쿠키 및 기타 사이트 데이터"를 체크하면 소설 데이터도 함께 삭제됩니다!
:::

## 회원 모드 (클라우드)

회원가입을 하면 **서버에 자동 백업**됩니다.

사이드바에 **"클라우드"** 뱃지가 표시됩니다.

### 회원의 장점

- 여러 기기에서 동일한 소설에 접근
- 브라우저 데이터가 삭제되어도 **로그인하면 복구**
- 안전한 서버 백업
- 공유 링크 생성 가능

## 게스트에서 회원으로 전환

게스트로 작성한 소설을 잃어버리지 않을까 걱정되시나요?

**걱정 마세요!** 같은 브라우저에서 회원가입하면, 게스트 데이터가 **자동으로 계정에 연동**됩니다.

### 전환 방법

1. 우측 상단 **회원가입** 클릭
2. 이메일로 가입
3. 기존 데이터 자동 연동!

::: tip 권장
소중한 원고를 안전하게 보관하려면 **회원가입**을 권장합니다.
:::

## 저장 방식 이해하기

4ndSYS는 **로컬 우선(Local-First)** 저장 방식을 사용합니다.

```
글쓰기 → 브라우저 저장 (즉시) → 서버 백업 (회원만, 온라인 시)
```

### 왜 로컬 우선인가요?

- **빠른 저장**: 네트워크 대기 없이 즉시 저장
- **오프라인 지원**: 인터넷 없어도 작업 가능
- **안정성**: 네트워크 불안정해도 데이터 손실 없음

### 로컬 저장 ≠ 안전한 저장

::: warning 중요
"로컬 우선 저장"은 **저장 속도**를 위한 것이지, **데이터 안전**을 보장하지 않습니다.

데이터 안전을 위해서는 반드시 **회원가입**을 해주세요.
:::
