# 게스트 vs 회원

> 회원가입 없이도 쓸 수 있다고요?

네! 4ndSYS는 **게스트 모드**를 지원합니다. 하지만 두 모드에는 중요한 차이가 있어요.

## 비교표

| 기능 | 게스트 | 회원 |
|------|:------:|:----:|
| 소설 작성 | ✅ | ✅ |
| 회차 관리 | ✅ | ✅ |
| 캐릭터 관리 | ✅ | ✅ |
| 관계도 | ✅ | ✅ |
| 자동 저장 | ✅ | ✅ |
| **클라우드 백업** | ❌ | ✅ |
| **다른 기기에서 접속** | ❌ | ✅ |
| **브라우저 데이터 삭제 후 복구** | ❌ | ✅ |

## 게스트 모드

게스트로 사용하면 모든 데이터가 **현재 브라우저의 IndexedDB**에만 저장됩니다.

::: warning 주의
브라우저 데이터를 삭제하면 소설도 함께 삭제됩니다!
:::

### 이런 경우 데이터가 사라져요

- 브라우저 캐시/쿠키 삭제
- 시크릿 모드 종료
- 브라우저 재설치
- 다른 브라우저에서 접속

## 회원 모드

회원가입을 하면 **클라우드 동기화**가 활성화됩니다.

- 여러 기기에서 동일한 소설에 접근
- 브라우저 데이터가 삭제되어도 복구 가능
- 안전한 백업

## 게스트에서 회원으로 전환

게스트로 작성한 소설을 잃어버리지 않을까 걱정되시나요?

**걱정 마세요!** 같은 브라우저에서 회원가입하면, 게스트 데이터가 **자동으로 계정에 연동**됩니다.

### 전환 방법

1. 우측 상단 **회원가입** 클릭
2. 이메일로 가입
3. 기존 데이터 자동 연동!

::: tip 권장
소중한 원고를 안전하게 보관하려면 **회원가입**을 권장합니다.
:::

## 로컬 우선 저장

4ndSYS는 **로컬 우선(Local-First)** 으로 설계되었습니다.

```
글쓰기 → IndexedDB 저장 (즉시) → 클라우드 동기화 (온라인 시)
```

이 덕분에:

- 저장이 빠름 (로컬 먼저 저장)
- 네트워크가 불안정해도 안전하게 저장
- 온라인 시 자동 동기화
