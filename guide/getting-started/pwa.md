# 앱처럼 사용하기 (PWA)

> 브라우저 없이도 4ndSYS를 사용할 수 있어요.

## PWA란?

**Progressive Web App**의 약자로, 웹사이트를 앱처럼 설치하여 사용하는 기술입니다.

- 홈 화면/독에 아이콘 추가
- 브라우저 주소창 없이 전체 화면 사용
- 오프라인에서도 작업 가능 (Chrome/Edge)

## 설치 방법

### Chrome / Edge (권장)

1. [4ndsys.net](https://4ndsys.net) 접속
2. 주소창 우측의 **설치** 아이콘 클릭
3. 또는 하단에 표시되는 **설치 배너** 클릭

::: tip 설치 배너
처음 방문하면 "앱으로 설치하기" 배너가 표시됩니다.
:::

### Safari (iOS)

::: warning 제한적 지원
Safari는 PWA를 제한적으로 지원합니다.
:::

1. Safari에서 [4ndsys.net](https://4ndsys.net) 접속
2. 하단 **공유** 버튼 탭
3. **"홈 화면에 추가"** 선택

**Safari 제한사항:**
- 오프라인 작업 불가
- 푸시 알림 미지원
- 자동 설치 프롬프트 없음

## 브라우저 vs 앱 모드

| 항목 | 브라우저 | 앱 (PWA) |
|------|----------|----------|
| 동기화 | 자동 (회원) | 수동 버튼 |
| 오프라인 | 불가 | 가능 (Chrome) |
| 화면 | 주소창 있음 | 전체 화면 |
| 설치 | 불필요 | 한 번만 |

## 앱 모드에서의 동기화

앱으로 설치하면 **자동 동기화가 비활성화**됩니다.

### 왜 수동 동기화인가요?

- 오프라인 작업 지원을 위해
- 네트워크 상태에 관계없이 빠른 저장
- 사용자가 원할 때만 동기화

### 동기화 방법

1. 사이드바 상단에서 **동기화** 버튼 확인
2. 버튼 클릭하여 서버와 동기화
3. 로그인이 필요합니다

::: info 비회원은?
비회원(게스트)도 앱으로 사용할 수 있습니다.
동기화하려면 회원가입이 필요합니다.
:::

## 오프라인 작업

Chrome/Edge에서 앱으로 설치하면 **오프라인에서도 글쓰기가 가능**합니다.

- 모든 데이터는 로컬(IndexedDB)에 저장
- 인터넷 연결 없이도 작업 가능
- 온라인이 되면 동기화 버튼으로 업로드

## 브라우저 지원 현황

| 브라우저 | 설치 | 오프라인 | 동기화 |
|----------|------|----------|--------|
| Chrome | 자동 프롬프트 | 완전 지원 | 수동 |
| Edge | 자동 프롬프트 | 완전 지원 | 수동 |
| Safari (iOS) | 수동 추가 | 미지원 | 미지원 |
| Firefox | 미지원 | 부분 지원 | - |
