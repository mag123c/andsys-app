# 앱처럼 사용하기 (PWA)

> 브라우저 없이도 4ndSYS를 사용할 수 있어요.

## PWA란?

**Progressive Web App**의 약자로, 웹사이트를 앱처럼 설치하여 사용하는 기술입니다.

- 홈 화면/독에 아이콘 추가
- 브라우저 주소창 없이 전체 화면 사용
- 오프라인에서도 작업 가능 (Chrome/Edge)

::: info PWA는 설치 방식의 차이일 뿐
PWA로 설치해도 데이터 저장 방식은 동일합니다.
**로그인 여부**가 데이터 안전성을 결정합니다.
:::

## 설치 방법

### Chrome / Edge (권장)

1. [4ndsys.net](https://4ndsys.net) 접속
2. 주소창 우측의 **설치** 아이콘 클릭
3. 또는 하단에 표시되는 **설치 배너** 클릭

::: tip 설치 배너
처음 방문하면 "앱으로 설치하기" 배너가 표시됩니다.
:::

### Safari (iOS)

::: warning 제한적 지원
Safari는 PWA를 제한적으로 지원합니다.
:::

1. Safari에서 [4ndsys.net](https://4ndsys.net) 접속
2. 하단 **공유** 버튼 탭
3. **"홈 화면에 추가"** 선택

**Safari 제한사항:**
- 오프라인 작업 불가
- 푸시 알림 미지원
- 자동 설치 프롬프트 없음

## PWA 설치의 장점

| 항목 | 브라우저 | 앱 (PWA) |
|------|----------|----------|
| 화면 | 주소창 있음 | 전체 화면 |
| 오프라인 | 불가 | 가능 (Chrome/Edge) |
| 설치 | 불필요 | 한 번만 |
| 앱 전환 | 탭에서 찾기 | 독/태스크바에서 바로 |

## 데이터 저장과 동기화

::: warning 중요
PWA든 브라우저든, 데이터 안전성은 **로그인 여부**로 결정됩니다.
:::

### 비회원 (게스트)

```
PWA든 브라우저든 동일:
- 데이터가 브라우저에만 저장됨
- 브라우저 데이터 삭제 시 복구 불가
- 다른 기기에서 접근 불가
```

### 회원 (로그인)

```
PWA든 브라우저든 동일:
- 데이터가 서버에 백업됨
- 브라우저 데이터 삭제해도 복구 가능
- 어떤 기기에서든 로그인하면 접근 가능
```

### 동기화 버튼

PWA에서 로그인하면 사이드바에 **동기화 버튼**이 표시됩니다.

- 버튼 클릭 시 서버와 동기화
- 오프라인에서 작업한 내용도 온라인 시 동기화 가능

## 오프라인 작업

Chrome/Edge에서 앱으로 설치하면 **오프라인에서도 글쓰기가 가능**합니다.

- 모든 데이터는 브라우저 내부(IndexedDB)에 저장
- 인터넷 연결 없이도 작업 가능
- 온라인이 되면 동기화 버튼으로 서버에 업로드 (회원만)

## 브라우저 지원 현황

| 브라우저 | 설치 | 오프라인 | 비고 |
|----------|------|----------|------|
| Chrome | 자동 프롬프트 | 완전 지원 | 권장 |
| Edge | 자동 프롬프트 | 완전 지원 | 권장 |
| Safari (iOS) | 수동 추가 | 미지원 | 제한적 |
| Firefox | 미지원 | 부분 지원 | - |

## 자주 묻는 질문

### PWA로 설치하면 데이터가 더 안전한가요?

아니요. PWA는 **설치 방식**의 차이일 뿐, 데이터 저장 방식은 동일합니다.
데이터 안전을 위해서는 **회원가입**을 해주세요.

### 브라우저 데이터를 삭제하면 PWA 데이터도 삭제되나요?

네. PWA도 브라우저의 저장소를 사용하므로, 브라우저 "사이트 데이터"를 삭제하면 함께 삭제됩니다.
회원이라면 다시 로그인하여 복구할 수 있습니다.

### PWA에서도 자동 동기화가 되나요?

현재는 PWA에서 **수동 동기화 버튼**을 사용합니다.
오프라인 작업 지원을 위해 이렇게 설계되었습니다.
