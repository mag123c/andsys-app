# 자주 묻는 질문

## 저장 관련

### 저장 버튼이 없어요!

4ndSYS는 **자동 저장** 방식입니다.

글을 쓰면 2초 후 자동으로 저장되며, 화면 상단에서 저장 상태를 확인할 수 있어요:

- **저장됨**: 모든 내용이 안전하게 저장됨
- **저장 중...**: 저장 진행 중
- **저장 안 됨**: 아직 저장되지 않은 내용 있음

급하게 저장하고 싶다면? `Ctrl+S` (Mac: `Cmd+S`)를 누르세요!

### 브라우저를 닫아도 저장되나요?

네! 탭을 닫거나 브라우저를 종료해도 마지막 내용이 저장됩니다.

브라우저 탭이 백그라운드로 가는 순간 자동 저장되도록 설계되어 있어요.

## 데이터 관련

### 게스트로 썼는데 데이터가 사라졌어요

게스트 모드는 **브라우저 로컬 저장소**만 사용합니다.

브라우저 데이터(쿠키, 캐시 등)를 삭제하거나, 다른 브라우저/기기에서 접속하면 데이터를 불러올 수 없어요.

::: tip
데이터를 안전하게 보관하려면 **회원가입** 후 클라우드 동기화를 사용하세요!
:::

### 게스트로 쓰다가 회원가입하면 기존 데이터는?

걱정 마세요! 같은 브라우저에서 회원가입하면 게스트 데이터가 **자동으로 계정에 연동**됩니다.

### 오프라인에서도 쓸 수 있나요?

네! 4ndSYS는 **오프라인 우선** 설계입니다.

인터넷이 끊겨도 글쓰기를 계속할 수 있어요. 다시 온라인이 되면 자동으로 서버와 동기화됩니다.

### 데이터 백업은 어떻게 하나요?

**설정 > 데이터 백업**에서 모든 소설과 회차를 JSON 파일로 내보낼 수 있어요.

[백업 방법 자세히 보기 →](/settings/backup)

## 에디터 관련

### 단축키가 있나요?

네! 자주 쓰는 단축키:

| 단축키 | 기능 |
|--------|------|
| `Ctrl+B` | 굵게 |
| `Ctrl+I` | 기울임 |
| `Ctrl+U` | 밑줄 |
| `Ctrl+S` | 즉시 저장 |
| `Ctrl+Z` | 실행 취소 |
| `Ctrl+Shift+Z` | 다시 실행 |

[전체 단축키 보기 →](/editor/shortcuts)

### 폰트를 바꿀 수 있나요?

네! 두 가지 방법이 있어요:

1. **에디터 툴바**에서 현재 문서의 폰트 변경
2. **설정 > 기본 폰트**에서 기본 폰트 설정

[폰트 변경 방법 →](/editor/font)

### 우측 패널이 뭔가요?

에디터 오른쪽에 있는 패널로, 글을 쓰면서 **시놉시스, 캐릭터, 회차 목록**을 참조할 수 있어요.

`◀` 버튼으로 접었다 펼 수 있습니다.

[우측 패널 활용법 →](/editor/right-panel)

## 기타

### 무료인가요?

네, 모든 기능을 **완전 무료**로 사용할 수 있습니다.

### 다른 사람이 내 소설을 볼 수 있나요?

아니요, 본인만 접근할 수 있습니다. 모든 데이터는 개인별로 안전하게 관리됩니다.

### 내보내기 형식은 뭐가 있나요?

현재 지원하는 형식:

- **TXT**: 순수 텍스트
- **클립보드 복사**: 서식 유지
- **JSON**: 전체 백업

EPUB/PDF 내보내기는 추후 지원 예정입니다.
