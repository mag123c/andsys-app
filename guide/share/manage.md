# 공유 링크 관리

> 내가 만든 공유 링크를 확인하고 관리할 수 있습니다.

## 공유 링크 목록 보기

**설정 > 공유 링크**에서 내가 만든 모든 공유 링크를 확인할 수 있습니다.

각 공유 링크에서 확인할 수 있는 정보:

- 프로젝트 및 회차 제목
- 생성일
- 만료일 (또는 무제한)
- 조회수
- 비밀번호 설정 여부

## 공유 링크 비활성화

더 이상 공유하고 싶지 않다면:

1. 설정 > 공유 링크 이동
2. 비활성화할 링크의 **삭제** 버튼 클릭
3. 확인 후 삭제

::: info 참고
비활성화된 링크는 더 이상 접근할 수 없습니다.
기존에 링크를 받은 사람도 내용을 볼 수 없게 됩니다.
:::

## 링크 복사하기

기존 공유 링크를 다시 복사하려면:

1. 설정 > 공유 링크 이동
2. 복사할 링크의 **복사** 버튼 클릭
3. 클립보드에 복사됨

## 자주 묻는 질문

### 공유 링크 수정이 가능한가요?

아니요, 만료 시간이나 비밀번호는 수정할 수 없습니다.
변경이 필요하면 기존 링크를 삭제하고 새로 만드세요.

### 조회수는 어떻게 계산되나요?

링크를 통해 내용을 볼 때마다 1회씩 증가합니다.
같은 사람이 여러 번 보면 그만큼 증가합니다.

### 만료된 링크는 자동 삭제되나요?

아니요, 목록에는 남아있습니다.
다만 해당 링크로는 더 이상 접근할 수 없습니다.
