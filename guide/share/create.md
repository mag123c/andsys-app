# 공유 링크 만들기

> 특정 회차를 다른 사람에게 공유하고 싶을 때 사용하세요.

공유 링크를 만들면 로그인 없이도 해당 회차를 읽을 수 있는 URL이 생성됩니다.

![공유 링크 생성 다이얼로그](/screenshots/share-dialog.png)

## 공유 링크 생성하기

1. 에디터에서 공유할 회차를 엽니다
2. 상단 툴바의 **공유** 버튼 클릭
3. 만료 시간 선택 (1시간 ~ 무제한)
4. 필요시 비밀번호 설정
5. **공유 링크 생성** 버튼 클릭
6. 생성된 링크를 복사하여 공유

## 만료 시간 옵션

| 옵션 | 설명 |
|------|------|
| 1시간 | 빠른 피드백용 |
| 24시간 | 기본값, 하루 동안 유효 |
| 7일 | 여유있게 공유 |
| 30일 | 장기 공유 |
| 무제한 | 만료 없음 |

::: tip 추천
피드백을 받을 목적이라면 **24시간**이 적당합니다.
:::

## 비밀번호 설정

민감한 내용이라면 비밀번호를 설정할 수 있습니다.

- 비밀번호가 있으면 링크를 열 때 비밀번호 입력 필요
- 비밀번호는 별도로 전달해야 함

::: warning 주의
공유 링크는 회원만 생성할 수 있습니다.
게스트 사용자는 먼저 회원가입이 필요합니다.
:::

## 공유되는 내용

공유 링크를 통해 볼 수 있는 정보:

- 프로젝트 제목
- 회차 번호와 제목
- 회차 본문 내용
- 글자수

::: info 스냅샷 저장
공유 시점의 내용이 저장됩니다.
원본을 수정해도 공유된 내용은 변하지 않습니다.
:::
