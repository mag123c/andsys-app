## 1. 회차 플롯 메모 기능

### 배경
- 현재 시놉시스는 **소설 전체**에 대한 줄거리
- 회차별 플롯/메모를 기록할 공간이 없음

### 요구사항
- 회차 에디터 상단에 플롯 메모 토글 영역 추가
- 접었다 펼 수 있는 형태

### UI 설계
```
┌─────────────────────────────────────────────────────┐
│ ← 목록  001화 제목                    미리보기 링크  │
├─────────────────────────────────────────────────────┤
│ ▼ 플롯 메모 (클릭하여 펼치기/접기)                   │
├─────────────────────────────────────────────────────┤
│ ┌─────────────────────────────────────────────────┐ │
│ │ 이 회차에서 일어날 일:                          │ │
│ │ - 주인공이 마을에 도착                          │ │
│ │ - 히로인과 첫 만남                              │ │
│ └─────────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────┤
│                                                     │
│              [본문 에디터 영역]                      │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 데이터 구조

**Option A: chapters 테이블에 필드 추가 (권장)**
```typescript
interface LocalChapter {
  // 기존 필드...
  plot: string | null;  // 플롯 메모 (plain text)
}
```

**Option B: 별도 테이블**
```typescript
interface LocalChapterPlot {
  id: string;
  chapterId: string;
  content: string;
  updatedAt: Date;
}
```

**권장:** Option A (단순, 회차와 1:1 관계)

### 변경 필요 파일
| 파일 | 변경 내용 |
|------|----------|
| `storage/local/db.ts` | chapters에 plot 필드 추가 (Dexie 버전 업) |
| `repositories/types/chapter.ts` | Chapter 타입에 plot 추가 |
| `storage/local/chapter.local.ts` | plot 필드 처리 |
| `storage/remote/chapter.remote.ts` | plot 필드 동기화 |
| `hooks/useEditor.ts` | plot 상태 관리 |
| `components/features/editor/` | PlotMemo 컴포넌트 추가 |
| `supabase/migrations/` | chapters 테이블에 plot 컬럼 추가 |

### 동작
1. 기본 접힘 상태
2. 클릭 시 펼침
3. 내용 수정 시 자동 저장 (본문과 동일한 debounce)
4. 펼침/접힘 상태 localStorage 저장

## 2. 우측 사이드바 개편 (회차 에디터)

### 배경
- 현재 우측 사이드바가 w-72 (288px)로 좁음
- 캐릭터/시놉시스가 읽기 전용
- 관계 설정이 별도 페이지에 분리되어 있음
- 글쓰기 중 참고/편집이 불편함

### 변경 방향
```
현재:
┌──────────────────────────────────────────────────────────────┐
│ 좌측 사이드바 │        에디터         │ 우측 (w-72, 읽기전용) │
│ (회차 목록)   │                       │ - 시놉시스 (읽기)     │
│               │                       │ - 등장인물 (읽기)     │
│               │                       │ - 관계도 (Dialog)     │
└──────────────────────────────────────────────────────────────┘

변경 후:
┌──────────────────────────────────────────────────────────────┐
│ 좌측 (접힘) │      에디터 (50%)      │   우측 (50%, 편집가능) │
│             │                        │ - 시놉시스 (편집)      │
│             │                        │ - 등장인물 (편집+관계) │
│             │                        │   └ [관계도 보기] 버튼 │
└──────────────────────────────────────────────────────────────┘
```

### 핵심 변경사항

#### 2.1 사이드바 연동
- 우측 사이드바 열기 → 좌측 사이드바 자동 접힘
- 우측 사이드바 닫기 → 좌측 사이드바 복원 (이전 상태)

#### 2.2 사이드바 너비
- 현재: `w-72` (288px) 고정
- 변경: 화면 **50%** (에디터와 동일 비율)

#### 2.3 시놉시스 탭 (편집 가능)
```
┌─────────────────────────────────────────────────────┐
│ 📄 시놉시스                           1,234자       │
├─────────────────────────────────────────────────────┤
│ ┌─────────────────────────────────────────────────┐ │
│ │                                                 │ │
│ │  [Tiptap 에디터 또는 Textarea]                  │ │
│ │                                                 │ │
│ │  자동 저장 (debounce 500ms)                     │ │
│ │                                                 │ │
│ └─────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────┘
```

#### 2.4 등장인물 탭 (나무위키 스타일 편집)
```
┌─────────────────────────────────────────────────────┐
│ 👤 등장인물 (5)          [+ 추가] [🔗 관계도 보기]  │
├─────────────────────────────────────────────────────┤
│ 검색: [_______________]                             │
├─────────────────────────────────────────────────────┤
│                                                     │
│ ┌─ 김철수 ──────────────────────────────────────┐  │
│ │ ┌───────┬───────────────────────────────────┐ │  │
│ │ │ 이미지 │  [프로필 사진 영역]               │ │  │
│ │ ├───────┼───────────────────────────────────┤ │  │
│ │ │ 이름  │  김철수                    [편집] │ │  │
│ │ ├───────┼───────────────────────────────────┤ │  │
│ │ │ 별명  │  철이                      [편집] │ │  │
│ │ ├───────┼───────────────────────────────────┤ │  │
│ │ │ 나이  │  25세                      [편집] │ │  │
│ │ ├───────┼───────────────────────────────────┤ │  │
│ │ │ 성별  │  남성                      [편집] │ │  │
│ │ ├───────┼───────────────────────────────────┤ │  │
│ │ │ 직업  │  대학생                    [편집] │ │  │
│ │ ├───────┼───────────────────────────────────┤ │  │
│ │ │ 성격  │  활발하고 정의감 강함      [편집] │ │  │
│ │ ├───────┼───────────────────────────────────┤ │  │
│ │ │ 배경  │  서울 출신, 부유한 가정... [편집] │ │  │
│ │ ├───────┴───────────────────────────────────┤ │  │
│ │ │ 관계                                      │ │  │
│ │ ├───────┬───────────────────────────────────┤ │  │
│ │ │ 홍길동│  친구 - 어린 시절 친구    [삭제] │ │  │
│ │ ├───────┼───────────────────────────────────┤ │  │
│ │ │ 이영희│  연인 - 대학 동기         [삭제] │ │  │
│ │ ├───────┼───────────────────────────────────┤ │  │
│ │ │       │  [+ 관계 추가]                    │ │  │
│ │ └───────┴───────────────────────────────────┘ │  │
│ └───────────────────────────────────────────────┘  │
│                                                     │
│ ┌─ 홍길동 ──────────────────────────────────────┐  │
│ │ ... (접힌 상태, 클릭하여 펼치기)              │  │
│ └───────────────────────────────────────────────┘  │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**나무위키 스타일 특징:**
- 라벨(좌) + 값(우) 테이블 형태
- 각 셀 hover 시 편집 버튼 표시
- 클릭 시 인라인 편집 (input/textarea로 전환)
- blur 또는 Enter 시 자동 저장
- 캐릭터 카드 접기/펼치기 (Accordion)

#### 2.5 관계도 보기 (읽기 전용)
- 등장인물 탭 상단 `[🔗 관계도 보기]` 버튼
- 클릭 시 모달 또는 전체 패널로 React Flow 표시
- 노드 클릭 → 해당 캐릭터로 스크롤 + 펼치기
- 관계 편집은 각 캐릭터 카드에서만 가능
- 2명 미만이면 버튼 비활성화

### UI 컬러 (나무위키 스타일 적용)
```css
/* 현재 디자인 컨벤션 기반 */

--border: hsl(var(--border));             /* 테두리 */

```

## 4. 회차 리스트 10화 단위 그룹핑

### 배경
- 회차가 많아지면 (100화, 400화 등) 스크롤이 길어짐
- 원하는 회차를 찾기 어려움

### UI 설계
```
회차 목록 (펼침)
├── ▼ 1~10화
│   ├── 001화 프롤로그          1,234자
│   ├── 002화 시작              2,100자
│   └── ...
├── ▶ 11~20화
├── ▶ 21~30화
└── ▶ 31~40화
```

### 동작
1. 현재 편집 중인 회차가 속한 그룹 자동 펼침
2. 다른 그룹은 기본 접힘
3. 그룹 클릭 시 펼침/접힘 토글
4. 10화 미만이면 그룹핑 없이 기존 방식

### 구현 방식
- DB 변경 없음
- UI에서 chapters 배열을 10개 단위로 그룹핑
- 그룹 헤더 렌더링 추가

### 변경 필요 파일
| 파일 | 변경 내용 |
|------|----------|
| `NovelSidebar.tsx` | 그룹핑 로직 + 그룹 UI 추가 |

### 유틸 함수
```typescript
function groupChaptersByTen(chapters: Chapter[]): ChapterGroup[] {
  // chapters를 order 기준 10개씩 그룹화
  // 예: [{start: 1, end: 10, chapters: [...]}, ...]
}
```

## 5. 사이드바 꺾쇠 자동 접기

### 배경
- 회차 목록 탭에서 꺾쇠 펼치고 → 시놉시스 이동 → 다시 회차 목록
- 펼침 상태가 유지되어 어수선함

### 변경 내용
```
현재:
- 탭 진입 시 해당 섹션 자동 펼침
- 다른 탭 이동해도 펼침 상태 유지

변경 후:
- 탭 진입 시 해당 섹션 자동 펼침
- 다른 탭 이동 시 자동 접힘
```

### 로직
```typescript
useEffect(() => {
  // 회차 탭이면 회차만 펼침, 나머지 접힘
  if (isChaptersActive) {
    setExpandedChapters(true);
    setExpandedCharacters(false);  // 추가
  }
  // 등장인물 탭이면 등장인물만 펼침
  if (isCharactersActive) {
    setExpandedChapters(false);    // 추가
    setExpandedCharacters(true);
  }
  // 그 외 탭이면 모두 접힘
  if (!isChaptersActive && !isCharactersActive) {
    setExpandedChapters(false);    // 추가
    setExpandedCharacters(false);  // 추가
  }
}, [pathname]);
```

### 변경 필요 파일
| 파일 | 변경 내용 |
|------|----------|
| `NovelSidebar.tsx` | useEffect 로직 수정 |
