## 1. 회차 플롯 메모 기능

### 배경
- 현재 시놉시스는 **소설 전체**에 대한 줄거리
- 회차별 플롯/메모를 기록할 공간이 없음

### 요구사항
- 회차 에디터 상단에 플롯 메모 토글 영역 추가
- 접었다 펼 수 있는 형태

### UI 설계
```
┌─────────────────────────────────────────────────────┐
│ ← 목록  001화 제목                    미리보기 링크  │
├─────────────────────────────────────────────────────┤
│ ▼ 플롯 메모 (클릭하여 펼치기/접기)                   │
├─────────────────────────────────────────────────────┤
│ ┌─────────────────────────────────────────────────┐ │
│ │ 이 회차에서 일어날 일:                          │ │
│ │ - 주인공이 마을에 도착                          │ │
│ │ - 히로인과 첫 만남                              │ │
│ └─────────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────┤
│                                                     │
│              [본문 에디터 영역]                      │
│                                                     │
└─────────────────────────────────────────────────────┘
```

### 데이터 구조

**Option A: chapters 테이블에 필드 추가 (권장)**
```typescript
interface LocalChapter {
  // 기존 필드...
  plot: string | null;  // 플롯 메모 (plain text)
}
```

**Option B: 별도 테이블**
```typescript
interface LocalChapterPlot {
  id: string;
  chapterId: string;
  content: string;
  updatedAt: Date;
}
```

**권장:** Option A (단순, 회차와 1:1 관계)

### 변경 필요 파일
| 파일 | 변경 내용 |
|------|----------|
| `storage/local/db.ts` | chapters에 plot 필드 추가 (Dexie 버전 업) |
| `repositories/types/chapter.ts` | Chapter 타입에 plot 추가 |
| `storage/local/chapter.local.ts` | plot 필드 처리 |
| `storage/remote/chapter.remote.ts` | plot 필드 동기화 |
| `hooks/useEditor.ts` | plot 상태 관리 |
| `components/features/editor/` | PlotMemo 컴포넌트 추가 |
| `supabase/migrations/` | chapters 테이블에 plot 컬럼 추가 |

### 동작
1. 기본 접힘 상태
2. 클릭 시 펼침
3. 내용 수정 시 자동 저장 (본문과 동일한 debounce)
4. 펼침/접힘 상태 localStorage 저장

## 2. 관계도 기능 개편

### 배경
- 현재 관계도가 사이드바에 별도 메뉴로 존재
- 부가 기능 느낌이 강함
- 캐릭터 편집과 관계 설정이 분리되어 있음

### 변경 방향
```
현재:
├── 회차 목록
├── 시놉시스
├── 등장인물 ← 별도 메뉴
└── 관계도   ← 별도 메뉴 (설정 + 시각화)

변경 후:
├── 회차 목록
├── 시놉시스
└── 등장인물
    ├── 캐릭터 목록
    ├── 캐릭터 추가/편집 (관계 설정 포함) ← NEW
    └── [관계도 보기] 버튼 → 시각화 (읽기 전용)
```

### 캐릭터 편집 다이얼로그 UI

```
┌─────────────────────────────────────────────────────┐
│ 캐릭터 편집                                    [X]  │
├─────────────────────────────────────────────────────┤
│ [기본 정보] [외형] [성격/배경] [관계]               │
├─────────────────────────────────────────────────────┤
│                                                     │
│ 다른 캐릭터와의 관계                                │
│                                                     │
│ ┌─────────────────────────────────────────────────┐ │
│ │ 홍길동                                          │ │
│ │ 관계: [친구 ▼]  설명: [어린 시절 친구]         │ │
│ │                                      [삭제]    │ │
│ └─────────────────────────────────────────────────┘ │
│                                                     │
│ ┌─────────────────────────────────────────────────┐ │
│ │ 이몽룡                                          │ │
│ │ 관계: [라이벌 ▼]  설명: [무술 대회 경쟁자]     │ │
│ │                                      [삭제]    │ │
│ └─────────────────────────────────────────────────┘ │
│                                                     │
│ [+ 관계 추가]                                       │
│                                                     │
├─────────────────────────────────────────────────────┤
│                              [취소]  [저장]         │
└─────────────────────────────────────────────────────┘
```

### 관계도 시각화 (읽기 전용)

```
등장인물 페이지
┌─────────────────────────────────────────────────────┐
│ 등장인물                        [+ 추가] [관계도]   │
├─────────────────────────────────────────────────────┤
│                                                     │
│  [캐릭터 카드들...]                                 │
│                                                     │
└─────────────────────────────────────────────────────┘

[관계도] 버튼 클릭 시:
- 모달 또는 슬라이드 패널로 React Flow 그래프 표시
- 노드 클릭 → 해당 캐릭터 편집 다이얼로그 오픈
- 관계 추가/삭제는 캐릭터 편집에서만 가능
- 2명 미만이면 버튼 비활성화 또는 숨김
```

### 변경 필요 파일
| 파일 | 변경 내용 |
|------|----------|
| `NovelSidebar.tsx` | 관계도 메뉴 제거 |
| `CharacterDialog.tsx` | 관계 설정 탭 추가 |
| `CharactersPage.tsx` | 관계도 보기 버튼 추가 |
| `RelationshipGraph.tsx` | 읽기 전용 모드 추가 |
| `app/(dashboard)/novels/[id]/relationships/` | 페이지 제거 또는 리다이렉트 |

### 데이터 구조
- 변경 없음 (기존 relationships 테이블 그대로 사용)

## 3. 사이드바 기본 닫힘

### 배경
- 회차 쓰기 시 사이드바가 작업 영역을 좁게 만듦
- 글쓰기 집중 모드 필요

### 변경 내용
```typescript
// 현재
const [collapsed, setCollapsed] = useLocalStorageBoolean(
  SIDEBAR_COLLAPSED_KEY,
  false  // 기본 열림
);

// 변경 후
const [collapsed, setCollapsed] = useLocalStorageBoolean(
  SIDEBAR_COLLAPSED_KEY,
  true   // 기본 닫힘
);
```

### 적용 범위

| 회차 에디터 | 열림 | **닫힘** |

## 4. 회차 리스트 10화 단위 그룹핑

### 배경
- 회차가 많아지면 (100화, 400화 등) 스크롤이 길어짐
- 원하는 회차를 찾기 어려움

### UI 설계
```
회차 목록 (펼침)
├── ▼ 1~10화
│   ├── 001화 프롤로그          1,234자
│   ├── 002화 시작              2,100자
│   └── ...
├── ▶ 11~20화
├── ▶ 21~30화
└── ▶ 31~40화
```

### 동작
1. 현재 편집 중인 회차가 속한 그룹 자동 펼침
2. 다른 그룹은 기본 접힘
3. 그룹 클릭 시 펼침/접힘 토글
4. 10화 미만이면 그룹핑 없이 기존 방식

### 구현 방식
- DB 변경 없음
- UI에서 chapters 배열을 10개 단위로 그룹핑
- 그룹 헤더 렌더링 추가

### 변경 필요 파일
| 파일 | 변경 내용 |
|------|----------|
| `NovelSidebar.tsx` | 그룹핑 로직 + 그룹 UI 추가 |

### 유틸 함수
```typescript
function groupChaptersByTen(chapters: Chapter[]): ChapterGroup[] {
  // chapters를 order 기준 10개씩 그룹화
  // 예: [{start: 1, end: 10, chapters: [...]}, ...]
}
```

## 5. 사이드바 꺾쇠 자동 접기

### 배경
- 회차 목록 탭에서 꺾쇠 펼치고 → 시놉시스 이동 → 다시 회차 목록
- 펼침 상태가 유지되어 어수선함

### 변경 내용
```
현재:
- 탭 진입 시 해당 섹션 자동 펼침
- 다른 탭 이동해도 펼침 상태 유지

변경 후:
- 탭 진입 시 해당 섹션 자동 펼침
- 다른 탭 이동 시 자동 접힘
```

### 로직
```typescript
useEffect(() => {
  // 회차 탭이면 회차만 펼침, 나머지 접힘
  if (isChaptersActive) {
    setExpandedChapters(true);
    setExpandedCharacters(false);  // 추가
  }
  // 등장인물 탭이면 등장인물만 펼침
  if (isCharactersActive) {
    setExpandedChapters(false);    // 추가
    setExpandedCharacters(true);
  }
  // 그 외 탭이면 모두 접힘
  if (!isChaptersActive && !isCharactersActive) {
    setExpandedChapters(false);    // 추가
    setExpandedCharacters(false);  // 추가
  }
}, [pathname]);
```

### 변경 필요 파일
| 파일 | 변경 내용 |
|------|----------|
| `NovelSidebar.tsx` | useEffect 로직 수정 |
