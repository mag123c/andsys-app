# Design System Redesign Requirements

## Original Request
"현재 프로젝트가 어떤 것인지, 어떤 사용자들이 들어올지 분석하고 VS Design Diverge skill을 사용해서 현재 프로젝트의 디자인 시스템을 모두 변경해주세요. 개인적으로 저는 첨부한 사진처럼 디지털한 느낌이 좋긴 하지만, 이 부분도 적합한지 검토해주세요."

## Clarified Requirements

### Goal
4ndSYS 웹소설 글쓰기 플랫폼의 디자인 시스템을 디지털/레트로 감성의 전체 리디자인

### Project Context
- **프로젝트**: 4ndSYS - 웹소설 작가를 위한 글쓰기 플랫폼
- **핵심 기능**: 회차 관리, 캐릭터 시트, 관계도, 오프라인 작업
- **기술 스택**: Next.js 16, React 19, Tailwind CSS 4, shadcn/ui

### Target User Persona
- **연령대**: 2030
- **특성**: 창작에 열정적, 감성적, 개성 있는 디자인 선호
- **익숙한 도구**: Notion, Obsidian 같은 모던 프로덕티비티 툴
- **기대**: 창작 영감을 주는 분위기, 독특하지만 사용하기 편한 UI

### Design Direction
- **스타일**: 전체적으로 디지털/레트로 무드
- **요소**: 색상, 폰트, 그림자, 아이콘 등 전반적 적용
- **참고 이미지**: 픽셀 아트 + 로봇 + 정원 테마 (밝고 따뜻한 색상)

### Scope
**포함**:
- globals.css 색상 테마 전면 수정
- 컴포넌트 스타일 커스터마이징
- 랜딩 페이지 리디자인
- 타이포그래피 조정

**제외**:
- 핵심 기능 로직
- 데이터 구조
- API/백엔드 변경

### Current Design Analysis
- 현재: shadcn/ui 기본 (무채색 중심, 미니멀)
- 색상: OKLCH 기반, 흑백 위주
- 폰트: Geist Sans/Mono (시스템 폰트 스타일)
- 스타일: 보수적이고 깔끔한 기본 shadcn 테마

### Success Criteria
- [ ] 기존 무채색 미니멀에서 개성 있는 디지털/레트로 감성으로 전환
- [ ] 창작자들에게 영감을 주는 분위기 조성
- [ ] 라이트/다크 모드 모두 일관된 테마 적용
- [ ] 기존 기능 정상 작동 유지

### Decisions Made
| Question | Decision |
|----------|----------|
| 변경 범위 | 전체 리디자인 (색상, 타이포그래피, 컴포넌트, 랜딩) |
| 타겟 사용자 | 창작에 열정적인 2030 |
| 디자인 방향 | 전체적으로 디지털/레트로 무드 |
