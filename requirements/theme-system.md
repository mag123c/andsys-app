# 테마 시스템 요구사항

## Original Requirement
"이 브렌치에 있는 디자인을, /main기준에서 "설정" 탭에 디자인테마 같은 느낌으로 골라서 쓸수있도록 할 수 있어?"

## Clarified Specification

### Goal
설정 페이지에서 "기본" 테마와 "디지털" 테마를 선택할 수 있는 테마 시스템 구현

### Scope
- 전체 앱에 테마 적용
- 디자인 스타일만 변경 (다크/라이트 모드는 별도 유지)
- 테마: "기본" (main 브랜치 디자인), "디지털" (현재 브랜치 디자인)
- 향후 3개 이상 테마로 확장 가능한 구조

### 저장 정책
| 상태 | 저장 위치 |
|------|----------|
| 비로그인 | 로컬 스토리지 |
| 로그인 | 서버 동기화 (다른 기기에서도 동일 테마) |

### Constraints
- 기존 다크/라이트 모드와 독립적으로 동작
- 확장 가능한 테마 아키텍처

### Success Criteria
- [ ] 설정 > 테마에서 "기본" / "디지털" 선택 가능
- [ ] 선택 시 전체 앱 스타일 즉시 변경
- [ ] 로그인 사용자는 다른 기기에서도 테마 유지

## Decisions

| Question | Decision |
|----------|----------|
| 적용 범위 | 전체 앱 |
| 테마 구성 | 디자인만 (다크/라이트 별도) |
| 저장 위치 | 로컬 + 로그인 시 서버 동기화 |
| 기본 테마 이름 | "기본" |
| 새 디자인 테마 이름 | "디지털" |
| 확장성 | 확장 가능 구조 필요 |
