## Clarified Requirements

### Goal
`feature/design-system-redesign` 브랜치의 디자인 개편 후 발생한 UI/UX 문제 전체 수정

### Scope
**포함**:
- 모든 페이지/컴포넌트의 스타일링 검토 및 수정
- 모달 위치 및 동작 수정
- 텍스트 가독성 개선
- PWA 프롬프트 디자인 통일

**유지**:
- Win95/레트로 모달 스타일 컨셉 (의도된 디자인)

### Constraints
- 레트로 디자인 컨셉 유지
- 텍스트 그림자 완전 제거
- 모달 중앙 배치 + 배경 딤(dim) 처리 필요

### Success Criteria
- [ ] 모든 텍스트 가독성 확보 (그림자 없음)
- [ ] 모달이 화면 중앙에 표시
- [ ] 모달 열림 시 배경 어두워짐 (overlay/backdrop)
- [ ] PWA 프롬프트가 레트로 테마와 일관됨
- [ ] 전체 페이지에서 스타일 일관성 확보

## Decisions Made

| 질문 | 결정 |
|------|------|
| 모달 스타일 | 레트로 컨셉 유지 (의도된 디자인) |
| 수정 범위 | 전체 검토 + 수정 |
| 텍스트 가독성 | 그림자 완전 제거 |
| 모달 동작 | 위치(중앙) + 배경 딤 모두 수정 |
| PWA 프롬프트 | 레트로 테마에 맞게 수정 필요 |
| 진행 방식 | 문제 발견 시 즉시 수정 |
